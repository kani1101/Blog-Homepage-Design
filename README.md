Project Scope:

Displays blog posts, categories, images, and featured content.
Provides easy navigation between different sections.
Creates a responsive and visually appealing blog interface.

Objective:

To design an attractive and easy-to-use blog homepage.
To provide an organised platform for presenting blog content.
